# Contributing to UrbanPulse AI

Thank you for your interest in contributing to UrbanPulse AI!

## Development Setup

1. Fork the repository
2. Clone your fork
3. Follow the setup instructions in [DEVELOPMENT.md](docs/DEVELOPMENT.md)

## Pull Request Process

1. Create a feature branch
2. Make your changes
3. Add tests
4. Update documentation
5. Submit a PR with a clear description

## Code Style

- Java: Follow Google Java Style Guide
- Python: Follow PEP 8
- TypeScript: Follow Angular Style Guide

## Testing

All PRs must include tests. Aim for >80% coverage.
